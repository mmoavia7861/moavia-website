What is checked?

This tool reads the text you enter (or title and description from HTML you paste), counts characters, and previews how the text could look. It does not claim to fetch a live website or determine actual Google rankings.

Use a distinct, accurate title and human-readable description for each page. Google title documentation · Google snippet documentation.

Worked example: a sample bakery page

Imagine a fictional bakery page about whole-grain bread. A possible title is Whole-Grain Bread | Example Bakery and a possible description is Explore whole-grain bread at Example Bakery, with ingredient information, pickup details and current availability. Enter those phrases in the checker, then watch the title and description character counters and illustrative snippet change. This example is fictional, not evidence that the bakery exists or ranks in search.

For a real website, replace the sample with the actual page title and an accurate description of what readers will find. If you have the HTML source, paste it and press Extract from pasted HTML. The tool extracts a title and meta description from the pasted text; it does not request the URL or run a full SEO audit. Copy the generated tags to your page, publish, and use Search Console to observe actual search behavior. Google may rewrite title links and snippets regardless of length.

Frequently asked questions

Does entering my page URL scan the live page?

No. The URL is only a label in the illustrative preview. To extract metadata, paste your page HTML or type the title and description yourself.

Does Google impose a fixed 60-character title limit?

No. Length counts are editorial hints. Google can shorten, replace or rewrite titles based on page content, query and device.

Is the preview an actual Google search result?

No. This is a simulated search-style display, not a live SERP, ranking check or guarantee that Google will show exactly the same text.

How should I use the results?

Write distinctive and helpful titles and descriptions that match the visible page. Publish the tags and verify your live page through Search Console if needed.
