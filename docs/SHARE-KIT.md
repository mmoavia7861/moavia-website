## One-tool LinkedIn post — Meta checker

A useful SEO sanity check is to review whether a page title and meta description are clear, relevant and distinct.

I built a free checker that counts characters, can read title/description tags from HTML you **paste**, and shows an **illustrative** search-style preview.

Tool: https://moaviaseo.com/tools/meta-title-description-checker/

It does not fetch a live URL, and the preview cannot predict Google's exact snippet. Feedback on the extraction and preview UX is welcome.

## One-tool LinkedIn post — Robots and sitemap

A sitemap should list real canonical URLs; robots.txt should contain deliberate crawl rules.

I built a free browser-based generator that produces both files from your own website origin, URL list and crawl directives.

Tool: https://moaviaseo.com/tools/robots-txt-sitemap-generator/

It doesn't auto-crawl a website or invent pages. Please review a generated robots.txt before deployment—`Disallow: /` can block the whole site.
