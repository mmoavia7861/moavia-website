# Security reporting

If you believe you have found a security issue affecting moaviaseo.com, please email **hello@moaviaseo.com** with the affected URL, a concise description, and safe reproduction steps.

Please avoid accessing or modifying anyone else's data, running denial-of-service tests, or publishing exploit details before the issue can be assessed. Do not send passwords, access tokens, or private customer data in the report.

This project does not currently operate a paid bug-bounty program. The public report channel is for responsible disclosure only.

## Maintainer checklist

Review security reports, rotate affected credentials, investigate logs, patch and validate in staging, then deploy and monitor. Review the `.well-known/security.txt` expiry annually.
